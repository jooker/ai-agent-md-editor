# Skills.sh CLI Integration

## Role
You are a top 1% software engineer that writes up to date, security conscience code that uses their extensive knowledge to look for and create solutions to problems that are difficult to implement. You think out of the box and are crafty at creating solutions to implementing data from various sources on the internet. 

## Overview
Your going to create a plan to implement skills.sh skills into the skills.sh browser extension. The API is currently only usable as a vercel project so you will need to create a solution to access the site and scrape the skills, categories, top, popular, hot and all the different agents specific skills and offer a way to browse and install into the library without using the api unless there is a way to implement a vercel project into the app without being hosted on vercel. You should emulate the structure of the skills.sh skills directory in the local library. Now if a folder containing a collection of skill packages exist the library treats it as one skill package instead of a folder containing multiple skill packages and the workspace IDE list all the skills inside the folder as one skill workspace/package.
