#Landing Page
##Overview
Create a landing page for PlanEaze to showcase the website with a video playing full screen  embedded in the page with a box with instructions for test users to log in if they have already been accepted for the beta test and recieved their access token or invitation link. It should take them to a page that has the login wizard  and taken to the teacher dashboard if their profile is already completed or to the profile editor to complete their profile if incomplete. The login page should be a seperate page from the app so users can't access parts of the website under construction unless they have recieved an invitation and then they can access any parts of the site their permissions allow.

**Steps**
- Landing page with a hero promotional video playing in the background and an overlay card or box with instructions for invited testers to login.
- Fallback to a hero image if unable or problem loading promotional video.
- A new page with a look and feel of the theme of the site with only the login wizard for invited users to login with their credentials.
- If user isn't approved tester then show them a page where they can sign up to be a tester and join the waitlist.
- Make sure the landing page is optimized for SEO and includes everything needed to show up at the top of the search engines and ai agents use for references and resources.
