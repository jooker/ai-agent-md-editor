Icon Format Guide

Windows ICO Bundle

A Windows ICO file containing multiple sizes (16×16, 32×32, 48×48, and 256×256 pixels) bundled into a single file. Use for:

  • Windows application icons
  • Desktop shortcuts
  • File type associations
  • Windows taskbar icons

Place in your application resources folder for Windows apps.

Favicon ICO

A 32x32 pixel ICO file specifically sized for website favicons. Use for:

  • Website browser tab icons
  • Bookmark icons

Place in your website's root directory and link it in your HTML:

<link rel="icon" href="favicon.ico" type="image/x-icon">

Android PNG

A 192x192 pixel PNG file for Android app icons. Use for:

  • Android app icons
  • Android home screen shortcuts

Place in your Android project's resources directory.

PWA PNG

A 512x512 pixel PNG file for Progressive Web Apps. Use for:

  • PWA application icons
  • Add to home screen features
  • Splash screens

Reference in your web app manifest file:

{
  "icons": [
    {
      "src": "icon-512x512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}
